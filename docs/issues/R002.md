## Outcome and scope

- Build responsive web Today/Diary/Add/Edit and SwiftUI Today/Diary/Add using the same authoritative API.

- Support multiple food items, manual nutrient/portion entry, notes, historical dates and confirmed/draft/deleted state.

- Show stable IDs, revision conflicts, source badges and honest app/Health statuses; keep web useful without an iPhone connection.

## Acceptance criteria

- [ ] Same record IDs, consumed quantities and current totals appear on desktop web and native iOS.

- [ ] Create/edit/delete on either client reaches the other and preserves history.

- [ ] Manual entry works before AI integration; inaccessible Health is never shown as confirmed.

## Validation and evidence

- Cross-client CRUD smoke tests and historic-date edit/delete flows; keyboard/mobile usability checks.
