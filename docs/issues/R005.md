## Outcome and scope

- Render structured meal descriptions/photo-derived proposals as reviewable food/portion/nutrient drafts with evidence and uncertainty.

- Distinguish actual saved app media IDs from ChatGPT-only attachment analysis and offer explicit app upload.

- Confirm real meal intent, consumed amounts and estimate policy before eligible Health writes; keep hypothetical meals drafts.

## Acceptance criteria

- [ ] User can inspect/edit/commit extraction using the common API; source and approval survive revisions.

- [ ] Photo analyzed in chat is never shown as retained unless bytes were uploaded successfully.

- [ ] Uncertain potassium cannot become a verified measurement.

## Validation and evidence

- Hypothetical vs instructed meal fixtures, missing media bytes and estimate-approval tests. Covers T-10/T-17.

## Boundaries

Implement only this issue; do not start later phases or optional enhancements.
