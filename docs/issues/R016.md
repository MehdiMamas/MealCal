## Outcome and scope

- Provide iOS ShareLink/Mail export first without requiring a server email provider.

- Optionally add explicit email-to-self using a configured verified sender, rate limits and attachment/short-lived access strategy.

- Track queued/sent/failed accurately and require report/destination confirmation.

## Acceptance criteria

- [ ] Actual PDF can be shared to Mail; delivery claims distinguish handoff from verified delivery.

- [ ] Optional server delivery works only when configured and consented, with meaningful failures.

- [ ] No permanent public report URL or unconfirmed arbitrary destination send.

## Validation and evidence

- On-device Mail sharing and, if configured, actual verified delivery/expired-link checks. Covers T-20; mark provider-dependent checks unrun if unavailable.

## Boundaries

Implement only this issue; do not start later phases or optional enhancements.
