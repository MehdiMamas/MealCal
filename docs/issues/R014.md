## Outcome and scope

- Complete diary calendar and 7/30/90/custom trends, editable targets, nutrient search/pinning and source/coverage filters.

- Show before/after media, consumed quantities, revisions, import origin and app-vs-Health status.

- Distinguish no-log vs known-zero days and estimated vs known coverage; add weight trends only with consent.

- Polish responsive web/native layout, accessibility, dark mode and localized dates.

## Acceptance criteria

- [ ] Every plotted daily total links to contributing current records and updates after historical edits.

- [ ] Potassium/sodium stay discoverable with coverage; missing days do not silently count as zero.

- [ ] Activity charts respect the chosen inclusion policy and provenance filters.

## Validation and evidence

- Chart aggregate fixtures, historical invalidation, 30/90-day comparison, accessible navigation and mobile layout checks.

## Boundaries

Implement only this issue; do not start later phases or optional enhancements.
