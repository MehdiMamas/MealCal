# Recompute historical days and invalidate derived totals after every edit

## Outcome and scope

- Derive daily totals from current nondeleted consumption items and invalidate dependent caches on additions, edits, deletions and date moves.

- Keep all historical dates editable with no midnight cutoff.

- Propagate revisions to dashboard, charts and export data paths; avoid mutable independent daily totals.

## Acceptance criteria

- [ ] Late entry last year appears on the correct day immediately.

- [ ] Deletion or date move updates both affected days and downstream aggregates.

- [ ] Imported report totals stay provenance evidence and never overwrite corrected ledger totals.

## Validation and evidence

- Past-year additions, date moves, deletion and cached summary invalidation tests; verify same revision is used by report aggregation.

Implement only this issue; do not start later phases or optional enhancements.
