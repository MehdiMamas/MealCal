## Outcome and scope

- Document versioned meal and patch JSON contracts with stable meal IDs/expected revision.

- Build /imports/chatgpt paste/file/share validation, diff preview and explicit commit through common meal APIs.

- Provide synthetic prompts/examples for structured drafts and historical corrections without requiring paid AI API usage.

## Acceptance criteria

- [ ] User can create/edit an old meal from valid JSON with preview and conflict handling.

- [ ] Unsupported ChatGPT connector access does not block normal product use.

- [ ] Embedded text instructions do not authorize extra operations or bypass the expected revision.

## Validation and evidence

- Valid/invalid schema, stale patch, duplicate submit, hypothetical examples and adversarial text tests.

## Boundaries

Implement only this issue; do not start later phases or optional enhancements.
