# Audit complete Cal AI 26.40.0 paid iPhone feature parity

<!-- mealcal-plan:P01 -->

**Roadmap:** [#37](https://github.com/MehdiMamas/MealCal/issues/37)

## Goal

Establish the evidence-backed baseline for replacing **Cal AI 26.40.0 on iPhone with a paid subscription**, as confirmed by the owner. The target is all everyday functionality plus the owner's additions, not only the original spec's feature subset. Read [the scope update](https://github.com/MehdiMamas/MealCal/blob/main/docs/CAL-AI-PARITY.md).

## Scope

- Start alongside F00 (#1); no application implementation is part of this audit.
- Inspect official listings, release notes, help material and reliable demonstrations, then the owner's redacted signed-in walkthrough. Record which evidence belongs to 26.40.0 and which may describe another release.
- Inventory every observed feature and hidden setting with stable parity ID, source/date, subscription/region context, steps, result and existing issue mapping.
- Use the discovery checklist in the scope document only as questions to investigate. Candidate features are not verified claims.
- Track unobserved paid/account-specific functionality as unknown. Do not invent current app behavior from memory or marketing images.
- Create narrowly scoped implementation issues for verified uncovered capabilities and promote baseline features out of optional status. Preserve original spec additions and architectural invariants.
- Resolve baseline AI capture versus the original no-extra-AI-cost/JSON-first preference explicitly; compare workflow friction and user-visible results.

## Acceptance criteria

- [ ] Target version/platform/paid status and remaining account-context unknowns are recorded.
- [ ] Evidence-backed feature matrix covers every observed surface; each row maps to implementation and validation ownership.
- [ ] Public-source claims, direct observation, owner reports and unknowns remain distinct.
- [ ] All confirmed gaps have issues and required parity priority; scope exceptions require explicit owner agreement.
- [ ] No assertion of complete coverage is based solely on public marketing material.
