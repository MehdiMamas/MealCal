## Outcome and scope

- Implement native camera/library and web upload, role/capture timestamps, before/after pairing, label/barcode metadata and thumbnails.

- Strip GPS EXIF, correct orientation, compress toward configurable 200–400 KB target; hash/dedupe retry uploads.

- Use owned private objects, short-lived signed uploads/downloads, limits and completion validation; delete only app copies.

## Acceptance criteria

- [ ] Both supplied photos attach to one meal and are visible to the owner on PC/iPhone.

- [ ] After photo is optional; missing bytes are never represented as stored media.

- [ ] Upload retry creates one logical asset; unauthorized or expired access fails and camera-roll originals remain untouched.

## Validation and evidence

- EXIF/orientation checks, ownership/signed-link expiry, duplicate upload, cancellation and offline recovery tests.

## Boundaries

Implement only this issue; do not start later phases or optional enhancements.
