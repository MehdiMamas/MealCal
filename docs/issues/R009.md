## Outcome and scope

- Build persistent desired-state outbox pull/reconcile/ack flow, retaining per-item/nutrient source UUID links and generations.

- Delete verified old owned samples and confirm before replacements; re-query ambiguous partial state before retrying.

- Handle tombstones, absent UUIDs, app kill/lock/offline, stale jobs and rapid revisions without losing older removals.

- Use bounded exponential retries, authenticated device acknowledgments and truthful pending/blocked/conflict status.

## Acceptance criteria

- [ ] Old-day edits/deletions reconcile without midnight filters or third-party deletion.

- [ ] 100 retries/rapid updates converge to latest desired values with zero duplicate owned samples.

- [ ] After delete succeeds but save/ack fails, restart converges safely; API success alone never means Health synced.

## Validation and evidence

- Fault-injection suite plus physical-iPhone evidence for T-01/T-02/T-03/T-04/T-13/T-19. Gate must pass before later feature polish.
